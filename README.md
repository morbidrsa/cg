# cg
cg - A Grep for CSV

```
grep for CVS

Usage: cg [OPTIONS] --column <COL> --value <VALUE> <FILE>

Arguments:
  <FILE>

Options:
  -c, --column <COL>   Name of the row to grep in
  -v, --value <VALUE>  The value to search for
  -H, --headers        The CSV has headers
  -h, --help           Print help
  -V, --version        Print version
```
